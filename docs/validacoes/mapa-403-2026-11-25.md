# Correção do mapa bloqueado

Atualização: 25/11/2026.

## Diagnóstico

O mapa Perto de você usava imagens raster diretamente de subdomínios tile.openstreetmap.org em um iframe srcDoc com sandbox allow-scripts. A captura do usuário mostrava as respostas Access blocked/403 como fundo, enquanto o Leaflet continuava desenhando os pins.

Um ensaio com o mesmo isolamento no Edge e um servidor de imagens local confirmou ausência de Referer nas requisições do iframe, inclusive com meta referrer origin. A [política do servidor de tiles OSM](https://operations.osmfoundation.org/policies/tiles/) exige identificação/Referer válidos para páginas Web. Alterar só os subdomínios ou inserir uma meta de referrer não corrigiria essa incompatibilidade do iframe isolado. Não foram falsificados User-Agent/Referer, criados proxies ou removidas as restrições de acesso ao documento principal.

## Implementação

Alterado apenas o frontend em `frontend/src/app/perto_de_voce.tsx`:

- Mantido Leaflet 1.9.4 para pins, zoom, enquadramento e centralização.
- Substituído o TileLayer raster pelo mapa vetorial Liberty do [OpenFreeMap](https://openfreemap.org/quick_start/), usando MapLibre GL JS 5.24.1 e o adaptador MapLibre GL Leaflet 0.1.3. Bibliotecas fixadas por versão e carregadas via CDN no iframe, conforme o padrão existente, sem alteração de package.json/lockfile.
- OpenFreeMap documenta uso público sem cadastro/API key e permite uso comercial. A API de estilos respondeu HTTP 200 com CORS *, compatível com o contexto isolado. Nenhuma chave Geoapify foi usada ou exposta.
- Mantidos pins de estabelecimento azuis, pins de programação laranja, fotos/iniciais e círculo da localização. Créditos de OpenFreeMap/OpenMapTiles/OpenStreetMap exibidos no mapa.
- Mantido sandbox sem allow-same-origin. Apenas popups isolados foram permitidos para abrir os links oficiais de atribuição em outra aba, com noopener/noreferrer nos links.
- Falha de bibliotecas, inicialização vetorial ou carregamento inicial apresenta mensagem amigável e nova tentativa explícita. Sem novas tentativas automáticas em loop. A lista de locais continua disponível.
- A falha fecha o card de seleção sobreposto, para não encobrir a mensagem e o botão. Nova tentativa recria somente o iframe. Mensagens de seleção/erro/retry exigem a janela do iframe atual, a origem lógica e o mapId esperado; mensagens de outras janelas são ignoradas.

## Validação realizada

- Lint e TypeScript aprovados.
- Exportação Expo Web aprovada em pasta temporária.
- Edge headless, viewport 430×900, localização e API de estabelecimentos simuladas; mapa real do provedor carregado somente para a área visível de Rosarinho/arredores. Sem varredura ou pré-download de tiles.
- Inspeção visual confirmou ruas, quarteirões, nomes de vias, controles, créditos e marcadores sem banners Access blocked. Canvas vetorial de 463×340; pin Host com borda rgb(25,118,210).
- Seleção de pin, exibição de card, falha simulada por ausência de biblioteca e recuperação por Tentar novamente verificadas. Iframe recriado com a biblioteca restaurada. Mensagem de retry enviada por janela incorreta ignorada.
- API e localização simuladas durante os testes; nenhuma gravação no banco ou alteração de backend.

## Limites

O mapa depende de internet, CDN, disponibilidade do OpenFreeMap e suporte WebGL no navegador. O serviço não oferece garantia de disponibilidade; a falha é apresentada sem esconder a lista. Outros navegadores/dispositivos não foram exercitados nesta entrega. O mapa nativo continua com a alternativa anterior. O embed de mapa nos detalhes da programação e a geocodificação Nominatim não foram alterados por este pedido.

Documentação: [OpenFreeMap](https://openfreemap.org/), [adaptador Leaflet](https://github.com/maplibre/maplibre-gl-leaflet), [Leaflet 1.9.4](https://leafletjs.com/reference-1.9.4.html). Nenhuma alteração de contrato da API, banco, protótipo externo ou PDFs.
